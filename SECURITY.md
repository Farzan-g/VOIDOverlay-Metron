# Security policy

## Supported releases

Security reports are welcome for the current development state. No formal release support window has been established yet.

## Reporting a vulnerability

Please report suspected vulnerabilities privately to the repository maintainers through GitHub's private vulnerability reporting feature, if enabled. Do not include credentials, personal data, or unrelated system information in a report.

This project does not currently publish a contact address or a repository URL. Do not send sensitive reports to an unverified address.

Metron is intended to remain a local, non-elevated utility. Reports involving external communication, privilege requirements, unsafe process access, or handling of private data are especially important.
